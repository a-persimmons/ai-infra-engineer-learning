## 考试概览

本实践考试考查部署与管理端到端 ML 基础设施系统的能力。你将容器化应用、部署至 Kubernetes、配置监控并排查问题。

## 环境配置

你将获得：
- 一个简单的 ML 模型（预训练 sklearn 或 PyTorch 模型）。
- 基础 Python 推理代码。
- Kubernetes 集群访问权限。
- 已安装的 Prometheus 与 Grafana。

## 第一部分：容器化（25 分）

### 任务 1.1：创建优化的 Dockerfile（15 分）

为所提供的 ML 推理应用创建符合以下要求的 Dockerfile：

**要求：**
- [ ] 使用 Python 3.11 基础镜像（2 分）。
- [ ] 实现多阶段构建（4 分）。
- [ ] 以非 root 用户运行（3 分）。

- [ ] 镜像大小低于 500MB（2 分）。
- [ ] 正确设置工作目录及复制文件（2 分）。

**交付物：** `Dockerfile`。

### 任务 1.2：用于本地测试的 Docker Compose（10 分）

创建 `docker-compose.yml`，运行：
- ML 推理服务。
- Redis（用于缓存）。
- Prometheus（用于指标）。

**要求：**
- [ ] 定义全部服务（3 分）。
- [ ] 服务间网络配置正确（3 分）。
- [ ] 配置健康检查（2 分）。
- [ ] 使用数据卷实现持久化（2 分）。

**交付物：** `docker-compose.yml`。

**测试：** 运行 `docker-compose up`，验证全部服务启动。

## 第三部分：监控配置（25 分）

### 任务 3.1：实现 Prometheus 指标（15 分）

向应用添加 Prometheus 指标：

**必需指标：**
- [ ] `predictions_total`——总预测数 Counter（3 分）。
- [ ] `prediction_duration_seconds`——延迟 Histogram（4 分）。
- [ ] `model_loaded`——模型状态 Gauge（3 分）。
- [ ] `prediction_errors_total`——错误 Counter（3 分）。
- [ ] 正确配置指标标签（model_name、version）（2 分）。

**交付物：** 添加指标后的应用代码。

### 任务 3.2：创建 Grafana 仪表盘（10 分）

创建 Grafana 仪表盘，包含：

**必需面板：**
- [ ] 请求速率（QPS）——图表（2 分）。

- [ ] 错误率——图表（2 分）。
- [ ] 活跃 Pod——Stat 面板（1 分）。
- [ ] 合适的时间范围及刷新配置（1 分）。
- [ ] 用于过滤的仪表盘变量（1 分）。

**交付物：** `dashboard.json`（导出的仪表盘）。

## 第四部分：故障排查与运维（20 分）

### 任务 4.1：调试问题（10 分）

你将获得一份存在故障的部署配置。诊断并修复以下问题：

**场景：** 提供的部署中有 3 个故意设置的问题。

**你的任务：**
1. 识别所有问题（3 分，每个 1 分）。
2. 修复每个问题（6 分，每项修复 2 分）。
3. 记录错误原因与修复方式（1 分）。

**可能的问题包括：**
- 镜像标签错误。
- 缺少环境变量。
- 端口配置错误。
- 资源限制过低。
- 健康检查配置错误。

**交付物：**
- 修复后的 YAML 文件。
- `TROUBLESHOOTING.md`，记录问题与修复。

### 任务 4.2：性能优化（10 分）

针对当前部署，识别并实现 3 项优化：

**优化领域：**
- [ ] 减少 Docker 镜像大小（3 分）。
- [ ] 优化资源分配（3 分）。
- [ ] 改善启动时间（2 分）。
- [ ] 添加缓存层（2 分）。

**交付物：** `OPTIMIZATIONS.md`，记录：
- 优化了什么。
- 优化前后的指标。
- 为什么能够提升性能。
