## 如何使用答案

### 面向学习者
1. **先完成测验**——尝试独立回答所有问题。
2. **对照答案**——将自己的回答与内嵌答案（如有）或讲义原始资料对照。
3. **理解错误**——重新测验之前，复习相关讲义章节。
4. **学习薄弱领域**——答错的问题所涉及的主题提示你应该在哪些方面投入学习时间。

### 面向教师
- 模块内的测验是权威来源。
- 在综合答案发布之前，根据每份测验对应的讲义推导正确答案。

## 学术诚信

答案（内嵌答案或计划中的答案）用于自主学习与实践。使用答案完成计分评估属于学术不端。

| 可接受 | 不可接受 |
|---|---|
| 完成测验后核对答案 | 测验前查看答案 |
| 为重测进行复习 | 为计分任务抄写答案 |
| 理解遗漏的概念 | 在测验进行期间分享答案 |
| 教学与辅导 | 帮助他人作弊 |

## 答案模板

编写各模块答案时，使用以下格式：

```markdown
# Module XX: [Module Name] — Answer Key

## Question 1
**Q:** [Question text]

**Answer:** [Correct answer letter and text]

**Explanation:**
[Why this is the correct answer]

**Common Mistakes:**
- [Mistake 1 and why it's wrong]
- [Mistake 2 and why it's wrong]

**Related Material:** [Lesson reference]

---
```
