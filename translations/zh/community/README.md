# 社区指南

欢迎加入 AI 基础设施工程师学习社区！

本目录包含参与学习社区、为课程作出贡献以及与其他学习者建立联系所需的资源。

## 如何参与

### 面向学习者

1. **加入讨论**——分享进度、提出问题、获得帮助。
2. **分享项目**——展示你的实现。
3. **提供反馈**——帮助改进课程。
4. **帮助他人**——回答其他学习者的问题。
5. **作出贡献**——添加练习、示例或文档。

### 面向贡献者

详细贡献指南参见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

## 社区资源

### 沟通渠道

- **GitHub Discussions**：[提问与分享想法](https://github.com/ai-infra-curriculum/ai-infra-engineer-learning/discussions)
- **GitHub Issues**：[报告 Bug 或请求功能](https://github.com/ai-infra-curriculum/ai-infra-engineer-learning/issues)
- **电子邮件**：ai-infra-curriculum@joshua-ferguson.com

### 获取帮助

1. **检查现有资源**——查阅 README、文档及讨论。
2. **搜索 Issue**——你的问题可能已经得到回答。
3. **在 Discussions 中提问**——附上相关背景。
4. **具体描述**——包含错误消息、代码片段以及已经尝试的方案。

### 如何提出好问题

一个好的问题应包含：
- **背景**：你正在学习哪个模块或项目？
- **目标**：你希望实现什么？
- **问题**：什么地方无法正常工作？附上错误消息。
- **尝试**：到目前为止尝试过哪些方法？
- **环境**：操作系统、Python 版本及相关工具。

**示例：**
```
Module 04 - Kubernetes: Issue with GPU scheduling

I'm working on the Kubernetes module's GPU scheduling exercise and can't get
the pod to access the GPU.

Error: "nvidia.com/gpu" resource not found

Environment: Ubuntu 22.04, Kubernetes 1.28, NVIDIA driver 535

What I've tried:
- Installed NVIDIA device plugin
- Verified node has GPU label
- Checked resource limits in deployment

Pod YAML: [paste minimal reproducible example]
```

## 社区期望

### 行为准则

这是一个学习社区。我们希望成员：

**尊重他人**
- 尊重每个人。
- 欢迎新成员。
- 对学习中的成员保持耐心。
- 提供建设性反馈。

**乐于助人**
- 慷慨分享知识。
- 清晰解释概念。
- 指向有帮助的资源。
- 肯定其他人的成果。

**保持专业**
- 讨论围绕主题进行。
- 避免垃圾信息及自我推广。
- 尊重知识产权。
- 正确标注贡献来源。

**不被允许的行为**
- 骚扰或歧视。
- 分享考核的答案。
- 抄袭。
- 垃圾信息或过度自我推广。

## 学习小组

### 寻找学习伙伴

希望有人相互监督或协作？

1. 在 Discussions 发帖：「寻找学习伙伴」。
2. 分享你的时区及空闲时间。
3. 说明你的经验水平。
4. 说明学习目标与时间安排。

### 学习小组活动建议

- **每周同步**——分享进度，讨论挑战。
- **结对编程**——共同完成练习。
- **代码审查**——相互审查项目。
- **模拟面试**——练习技术面试。
