# 第 01 课：机器学习基础设施导论

**时长：** 3 小时
**目标：** 理解机器学习基础设施领域、职业发展路径和核心概念。

## 欢迎！

欢迎开启 AI 基础设施工程的学习之旅！本课介绍一个快速发展的领域，它处于机器学习、软件工程和基础设施运维的交汇处。

## 什么是机器学习基础设施？

**机器学习基础设施（ML Infrastructure）** 是使机器学习模型能够在生产环境中构建、部署和维护的一系列系统、工具和实践方法。

可以这样理解：

- **数据科学家**设计并训练模型。
- **机器学习基础设施工程师**构建使这些模型能够在现实世界中发挥作用的系统。

### 核心职责

作为机器学习基础设施工程师，你将：

1. **部署机器学习模型**至生产环境。
2. **构建数据管道**，为模型提供训练和推理所需的数据。
3. **监控系统**的性能、可靠性和模型质量。
4. **优化基础设施**的成本、速度和可扩展性。
5. **自动化训练、测试和部署工作流**。
6. **管理计算资源**，包括 GPU 和分布式系统。
7. **与数据科学家合作**，将需求转化为基础设施能力。

### 挑战

机器学习基础设施具有独特的挑战：

- **模型并非静态的** — 需要重新训练、版本管理和 A/B 测试。
- **数据至关重要** — 数据质量、版本管理和血缘关系都会影响模型性能。
- **计算成本高昂** — GPU 和分布式训练需要大量成本。
- **规模很重要** — 推理服务可能需要处理每秒数百万次请求。
- **故障难以察觉** — 模型性能可能随着时间推移悄然退化。

## 机器学习基础设施与传统基础设施

| 传统基础设施 | 机器学习基础设施 |
|---|---|
| 部署静态应用 | 部署随时间变化的模型 |
| 关注可用性和性能 | 额外关注模型质量与数据质量 |
| 代码版本管理（Git） | 代码、数据、模型版本管理 |
| 根据流量扩缩容 | 根据流量和训练工作负载扩缩容 |
| 常规监控（CPU、内存、请求） | 额外监控模型指标（准确率、漂移、偏差） |
| Docker、Kubernetes、CI/CD | 额外使用 MLflow、Airflow、专门的 GPU 管理 |

**机器学习基础设施建立在传统 DevOps/SRE 技能之上**，但增加了机器学习特有的关注点。

## 什么是 MLOps？

**MLOps（Machine Learning Operations，机器学习运维）** 是结合机器学习、DevOps 和数据工程的一系列实践，其目的在于：

- 在生产环境中可靠、高效地部署和维护机器学习系统。
- 自动化从数据采集到模型部署的机器学习生命周期。
- 持续监控并改进模型。

### MLOps 生命周期

```
┌─────────────────────────────────────────────────────────────┐
│                     ML Lifecycle                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. DATA              2. TRAINING           3. DEPLOYMENT   │
│  Collection  ──────>  Experiment   ──────>  Production     │
│  Preparation          Validation            Serving        │
│  Versioning           Model Registry        Monitoring     │
│                                                             │
│                  ┌──────────────────┐                      │
│                  │    FEEDBACK      │                      │
│                  │  Performance     │                      │
│                  │  Monitoring      │                      │
│                  │  Retraining      │                      │
│                  └──────────────────┘                      │
│                          │                                  │
│                          └────────────────────────┐         │
│                                                   ↓         │
│                                         (Continuous Loop)   │
└─────────────────────────────────────────────────────────────┘
```

图中三个主要阶段依次为：数据（采集、准备、版本管理）、训练（实验、验证、模型注册）和部署（生产环境、模型服务、监控）。反馈环节包括性能监控和重新训练，形成持续循环。

### MLOps 的三大支柱

1. **人员（People）** — 数据科学家、机器学习工程师和基础设施团队之间的合作。
2. **流程（Process）** — 标准化实验、测试和部署工作流。
3. **平台（Platform）** — 支撑机器学习生命周期的自动化基础设施和工具。

## 为什么机器学习基础设施重要？

### 业务影响

- **速度：** 缩短从模型开发到在生产环境中创造价值的时间。
- **可靠性：** 通过监控和重新训练，使生产模型保持良好性能。
- **规模：** 高效处理每秒数百万次预测。
- **成本：** 优化昂贵的 GPU 和云资源。

### 现实案例

**Netflix** — 机器学习基础设施为超过 2 亿用户提供个性化推荐。

- 挑战：在巨大规模下以低于 100ms 的延迟提供推荐。
- 方案：具备高级缓存能力的分布式模型服务基础设施。

**Uber** — 机器学习基础设施支撑定价、预计到达时间（ETA）和司机匹配。

- 挑战：在全球不同城市提供高准确率的实时预测。
- 方案：用于模型训练、部署和监控的 Michelangelo 平台。

**OpenAI** — 机器学习基础设施支撑 ChatGPT 和 API 服务。

- 挑战：大规模提供具有数十亿参数的大语言模型服务。
- 方案：结合模型优化的定制推理基础设施。

## AI 基础设施职业发展路径

### 入门级：AI 基础设施工程师

**薪资：** 10.7 万–23 万美元。
**重点：** 部署和维护机器学习系统、构建管道、监控基础设施。
**技能：** Python、Docker、Kubernetes 基础、云平台、MLOps 工具。

### 中级：高级 AI 基础设施工程师

**薪资：** 15 万–28 万美元。
**重点：** 设计可扩展系统、优化性能、指导初级工程师、领导项目。
**技能：** Kubernetes 进阶、分布式训练、GPU 优化、多云。

### 高级：AI 基础设施架构师

**薪资：** 16.5 万–35 万美元。
**重点：** 设计企业级机器学习平台、制定战略、建立标准。
**技能：** 企业架构、安全与合规、成本优化、领导力。

### 高管级：高级 AI 基础设施架构师

**薪资：** 20 万–50 万美元以上。
**重点：** 企业转型、创新、思想领导力、为高管提供咨询。
**技能：** 战略视野、高管沟通、行业影响力、全球化架构。

## 你将学习的关键技术

### 基础设施与编排

- **Docker：** 机器学习应用容器化。
- **Kubernetes：** 大规模容器编排。
- **Terraform：** 基础设施即代码。
- **Helm：** Kubernetes 包管理。

### 机器学习框架与工具

- **PyTorch：** 用于研究和生产的深度学习框架。
- **TensorFlow：** 端到端机器学习平台。
- **Hugging Face：** 预训练模型与 Transformer。

### MLOps 平台

- **MLflow：** 实验追踪和模型注册。
- **Airflow：** 工作流编排。
- **DVC：** 数据版本控制。
- **Kubeflow：** Kubernetes 上的端到端机器学习。

### 云平台

- **AWS：** SageMaker、EKS、EC2 GPU 实例。
- **GCP：** Vertex AI、GKE、TPU。
- **Azure：** Azure ML、AKS。

### 模型服务

- **TorchServe：** PyTorch 模型服务。

### GPU 计算

- **Horovod：** 分布式训练。

## 行业趋势（2025 年）

### 1. LLM 基础设施至关重要

大语言模型（GPT 系列、Llama 等）需要专门的基础设施：

- **推理优化：** 使用 vLLM、TensorRT-LLM，实现 3–5 倍加速。
- **RAG 系统：** 结合向量数据库实现检索增强生成。
- **成本管理：** 大规模 LLM 服务的每月成本可能超过 100 万美元。

### 2. 多云采用

原文称 78% 的企业使用多个云服务提供商：

- **避免厂商锁定：** 采用与云厂商无关的架构。
- **优化成本：** 为每种工作负载选择价格最优的方案。
- **监管要求：** 满足数据驻留与合规要求。

### 3. 绿色 AI 与成本优化

行业越来越关注可持续性与效率：

- **FinOps：** 面向云成本管理的财务运营。
- **碳感知计算：** 在碳排放较低的时段调度工作负载。
- **模型效率：** 采用性能相近但更小、更快的模型。

### 4. 负责任的 AI 基础设施

基础设施必须支持符合伦理与合规要求的 AI：

- **偏差检测：** 监控模型公平性。
- **可解释性：** 追踪并解释模型决策。
- **合规：** GDPR、HIPAA、SOC 2、欧盟 AI 法案。
- **隐私：** 联邦学习、差分隐私。

### 5. 平台工程

从单个工具向综合平台转变：

- **内部机器学习平台：** 为数据科学家提供自助服务。
- **开发者体验：** 抽象复杂性，提供 API。
- **治理：** 集中管理模型与合规。

## 优秀的机器学习基础设施工程师具备什么能力？

### 技术技能

- **编程：** 扎实的 Python，熟悉 Go/Bash。
- **系统思维：** 理解大规模系统中组件之间的交互。
- **云平台专业能力：** 深入掌握至少一个云平台。
- **调试能力：** 定位并解决复杂生产问题。
- **自动化思维：** 尽可能脚本化，采用 IaC。

### 软技能

- **协作：** 与数据科学家和工程师高效合作。
- **沟通：** 面向不同受众解释技术概念。
- **问题解决：** 为新的挑战提出创造性方案。
- **快速学习：** 技术演进迅速，需要持续跟进。
- **关注细节：** 微小的配置错误也可能造成灾难性后果。

### 思维方式

- **生产优先：** 系统不仅要能运行，还必须可靠。
- **成本意识：** 每项决策都有财务影响。
- **以用户为中心：** 帮助数据科学家提高生产力。
- **质量驱动：** 自动化测试、监控、文档。
- **持续改进：** 不断优化，不满足于现状。

## 学习方法

### 60% 实践，40% 理论

本课程优先培养实践技能：

- **每个概念都有练习** — 学完即练。
- **三个主要项目** — 构建真实系统作为作品集。
- **行业工具与实践** — 学习优秀企业实际使用的技术和方法。
- **调试与故障排查** — 学习解决真实问题。

### 建立作品集

每个完成的项目都会丰富你的 GitHub 作品集：

- 向潜在雇主**展示能力**。
- 为面试提供你亲手构建真实系统的**讨论素材**。
- **展示代码质量**和编写文档的能力。
- 证明超越理论知识的**实践经验**。

## 如何最大化本课程的学习收益

### 最佳实践

1. **跟着编写代码** — 亲手输入，而非复制粘贴。
2. **主动破坏系统** — 实验、犯错、调试。
3. **记录学习成果** — 记录错误与解决方案。
4. **建立作品集** — 将全部成果保存在个人 GitHub 仓库。
5. **加入社区** — 向其他学习者学习，也帮助他们。
6. **主动提问** — 使用 GitHub Discussions 和 Issues。
7. **立即应用** — 在工作或个人项目中尝试所学概念。

### 时间管理

- **安排专门学习时间** — 持续学习比突击更有效。
- **从小目标开始** — 每天 30 分钟积累学习动力。
- **追踪进度** — 标记已完成模块。
- **适当休息** — 复杂主题需要认知恢复时间。
- **定期复习** — 回顾早期模块，巩固知识。

- 持续学习和成长的机会。
