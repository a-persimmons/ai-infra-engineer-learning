## 如何使用这些实验

每个实验都是可以在笔记本电脑上完成的实操任务。实验文件采用统一结构：

- **目标** — 用一段文字说明完成实验后将得到什么。
- **前置条件** — 必须安装和配置的内容。
- **步骤** — 编号步骤，附确切命令和预期输出。
- **验证** — 判断实验是否成功的方法（不要跳过）。
- **清理** — 撤销已完成的环境配置。
- **故障排查** — 我们实际遇到过的问题。

开始前先通读一遍实验。如果某个步骤的实际输出与预期不一致，请停止并排查；现在解决问题的代价比在下游调试更低。
