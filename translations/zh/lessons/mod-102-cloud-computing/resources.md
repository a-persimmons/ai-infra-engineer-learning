## 书籍

### 云计算基础
1. **《Architecting the Cloud: Design Decisions for Cloud Computing Service Models》**——Michael J. Kavis
   - 云架构模式综合指南。
   - 重点介绍 SaaS、PaaS、IaaS 设计决策。
2. **《Cloud Native Transformation》**——Pini Reznik、Jamie Dobson、Michelle Gienow
   - 云原生系统实践模式。
   - 企业真实案例研究。

### AWS 专项
3. **《AWS Certified Solutions Architect Study Guide》**——Ben Piper、David Clinton
   - 深入介绍 AWS 核心服务。
   - 适合理解 AWS 架构模式。
4. **《Machine Learning on AWS》**——Janine Garzik、Kevin Huddy（原文署名）
   - 聚焦 AWS ML 服务（SageMaker 等）。
   - 动手示例及最佳实践。

### GCP 专项
5. **《Google Cloud Platform in Action》**——JJ Geewax
   - GCP 服务综合入门。
   - 实用示例及架构模式。
6. **《Building Machine Learning Pipelines on Google Cloud Platform》**——Hannes Hapke、Catherine Nelson（原文书名）
   - GCP 端到端 ML 工作流。
   - 聚焦 Vertex AI 与 TFX。

### Azure 专项
7. **《Microsoft Azure for Dummies》**——Jack Hyman
   - 面向初学者的 Azure 入门。
   - 涵盖核心服务与概念。
8. **《Azure Machine Learning Engineering》**——Sina Fakhraee
   - Azure ML 综合指南。
   - Azure 生产 ML 最佳实践。

### 成本优化
9. **《Cloud FinOps》**——J.R. Storment、Mike Fuller
   - 云财务运营。
   - 成本优化策略与文化。
