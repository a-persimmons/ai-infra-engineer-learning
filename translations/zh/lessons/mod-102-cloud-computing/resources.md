## 书籍

### 云计算基础
1. **《Architecting the Cloud: Design Decisions for Cloud Computing Service Models》** — Michael J. Kavis
   - 云架构模式全面指南。
   - 重点讨论 SaaS、PaaS、IaaS 的设计决策。
2. **《Cloud Native Transformation》** — Pini Reznik、Jamie Dobson、Michelle Gienow
   - 云原生系统实践模式。
   - 企业真实案例。

### AWS 专项
3. **《AWS Certified Solutions Architect Study Guide》** — Ben Piper、David Clinton
   - 深入介绍 AWS 核心服务。
   - 适合理解 AWS 架构模式。
4. **《Machine Learning on AWS》** — Janine Garzik、Kevin Huddy
   - 重点介绍 AWS ML 服务（SageMaker 等）。
   - 动手示例和最佳实践。

### GCP 专项
5. **《Google Cloud Platform in Action》** — JJ Geewax
   - GCP 服务全面入门。
   - 实践示例与架构模式。
6. **《Building Machine Learning Pipelines on Google Cloud Platform》** — Hannes Hapke、Catherine Nelson
   - GCP 端到端 ML 工作流。
   - 重点介绍 Vertex AI 和 TFX。

### Azure 专项
7. **《Microsoft Azure for Dummies》** — Jack Hyman
   - 适合初学者的 Azure 入门。
   - 涵盖核心服务及概念。
8. **《Azure Machine Learning Engineering》** — Sina Fakhraee
   - Azure ML 全面指南。
   - Azure 上的生产 ML 最佳实践。

### 成本优化
9. **《Cloud FinOps》** — J.R. Storment、Mike Fuller
   - 云财务运营。
   - 成本优化策略与文化。
