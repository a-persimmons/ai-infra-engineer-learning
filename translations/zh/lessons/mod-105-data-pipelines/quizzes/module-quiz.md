## 第一部分：Apache Airflow 基础（第 1–6 题）

### 第 1 题
Apache Airflow 在 ML 基础设施中的主要用途是什么？

A) 训练机器学习模型
B) 编排并调度复杂的数据工作流
C) 提供模型预测服务
D) 存储训练数据

**答案：** B

### 第 2 题
在 Airflow 中，DAG 代表什么？

A) Data Aggregation Graph（数据聚合图）
B) Directed Acyclic Graph（有向无环图）
C) Dynamic Algorithm Generator（动态算法生成器）
D) Distributed Application Gateway（分布式应用网关）

**答案：** B

---

### 第 3 题

**答案：** 错误（DAG 必须无环，不允许循环）。

---

### 第 4 题

A) Scheduler
B) Web Server
C) Executor
D) Metadata Database

**答案：** C

### 第 5 题
Airflow 中 `depends_on_past` 参数的用途是什么？

A) 当前一个 DAG Run 失败时阻止任务运行
B) 在任务之间共享数据
C) 在过去的时间调度任务
D) 检查任务依赖

**答案：** A（原文答案；准确含义见译注）。

---

### 第 6 题（简答）
解释 Airflow 中 `CeleryExecutor` 与 `LocalExecutor` 的区别。

**参考答案：**
- **LocalExecutor：** 使用多进程在单台机器上并行运行任务，适合开发及小规模部署。
- **CeleryExecutor：** 使用 Celery 将任务分发至多台 Worker 机器，适合需要水平扩展的生产环境。

### 第 15 题（简答）
解释 Spark 中的 Shuffle 是什么，以及为什么开销较大。

**参考答案：**
Shuffle 是跨分区重新分配数据的过程，通常由 `groupBy()`、`join()` 或 `reduceByKey()` 等操作触发。开销较大的原因：
- 可能需要磁盘 I/O 写入中间结果。
- 涉及 Executor 之间的网络数据传输。
- 可能导致内存压力及溢写至磁盘。
- 增加作业执行延迟。

A) 完整性
B) 准确性

D) 一致性

ML 中的数据漂移是什么？

A) 数据在传输过程中损坏
B) 数据的统计属性随时间变化
C) 数据被意外删除
D) 数据存储于错误位置

**答案：** B

---

### 第 22 题（简答）
列出 ML 训练管道中应实现的三种常见数据质量检查。

**参考答案：**
1. **空值/缺失值检查：** 确保关键列没有过多空值。
2. **范围验证：** 检查数值是否处于预期范围内（如年龄在 0–120 之间）。
3. **Schema 验证：** 验证预期列存在且数据类型正确。
4. **唯一性检查：** 确保 ID 列没有重复项。
5. **分布检查：** 检测数据分布是否发生显著变化。

（任选三项即可。）
