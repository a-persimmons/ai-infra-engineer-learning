## 第一部分：Apache Airflow 基础（1–6）

### 第 1 题

Apache Airflow 在 ML 基础设施中的主要用途是什么？

A) 训练 ML 模型  
B) 编排与调度复杂数据工作流  
C) 提供模型预测  
D) 存储训练数据

**答案：** B

---

### 第 2 题

Airflow 中 DAG 的全称是什么？

A) Data Aggregation Graph（数据聚合图）  
B) Directed Acyclic Graph（有向无环图）  
C) Dynamic Algorithm Generator（动态算法生成器）  
D) Distributed Application Gateway（分布式应用网关）

**答案：** B

---

### 第 3 题

判断题：Airflow DAG 中的任务可以具有循环依赖。

**答案：** 错误（DAG 必须无环，不允许循环）。

---

### 第 4 题

Airflow 中哪个组件负责执行任务？

A) Scheduler  
B) Web Server  
C) Executor  
D) Metadata Database

**答案：** C

---

### 第 5 题

Airflow 中 `depends_on_past` 参数的作用是什么？

A) 如果上次 DAG 运行失败，则阻止任务运行  
B) 在任务间共享数据  
C) 在过去调度任务  
D) 检查任务依赖

**答案：** A

---

### 第 6 题

简答：解释 Airflow 中 `CeleryExecutor` 与 `LocalExecutor` 的区别。

**参考答案：**

- **LocalExecutor：** 使用多进程在单台机器上并行执行任务，适合开发与小规模部署。
- **CeleryExecutor：** 使用 Celery 将任务分布到多个 Worker，适合需要水平扩展的生产环境。

### 第 15 题

简答：解释 Spark 中 Shuffle 的含义及其为何昂贵。

**参考答案：**

Shuffle 是跨分区重新分布数据的过程，通常由 `groupBy()`、`join()` 或 `reduceByKey()` 等操作触发。开销包括：
- 磁盘 I/O，写入中间结果。
- Executor 之间的网络传输。
- 内存压力及溢写磁盘。
- 增加作业执行延迟。

## 第五部分：数据质量与验证（20–22）

B) 准确性

A) 传输过程中数据损坏  
B) 数据统计特性随时间变化  
C) 数据意外删除  
D) 数据保存在错误位置

**答案：** B

---

### 第 22 题

简答：列举 ML 训练管道中应实现的三种常见数据质量检查。

**参考答案：**

1. **空值/缺失值检查：** 关键列不应有过多空值。
2. **范围验证：** 数值处于预期范围，例如年龄 0–120。
3. **Schema 验证：** 预期列存在且类型正确。
4. **唯一性检查：** ID 列无重复。
5. **分布检查：** 检测数据分布是否显著变化。

（任意三项均可。）
