## 工具与实用程序

### Terraform 工具

1. **tfenv** - Terraform 版本管理器
   - URL: https://github.com/tfutils/tfenv
   - 管理多个 Terraform 版本
   - 类似 pyenv、nvm

2. **tflint** - Terraform 静态检查工具
   - URL: https://github.com/terraform-linters/tflint
   - 发现错误并强制执行规范
   - 面向云服务商的插件系统

3. **terraform-docs** - 文档生成器
   - URL: https://github.com/terraform-docs/terraform-docs
   - 自动生成模块文档
   - 支持 Markdown、JSON、YAML 输出

4. **tfsec** - 安全扫描器
   - URL: https://github.com/aquasecurity/tfsec
   - 对安全问题进行静态分析
   - 数百项安全检查
   - CI/CD 集成

5. **Checkov** - 策略即代码扫描器
   - URL: https://github.com/bridgecrewio/checkov
   - 1000 多条内置策略
   - AWS、Azure、GCP、Kubernetes
   - Terraform、CloudFormation、Kubernetes

6. **Terrascan** - 安全扫描器
   - URL: https://github.com/tenable/terrascan
   - 500 多条策略
   - 合规框架（PCI-DSS、HIPAA）

7. **Infracost** - 成本估算
   - URL: https://www.infracost.io/
   - 估算基础设施成本
   - GitHub 集成
   - 个人免费

8. **Atlantis** - Terraform 自动化
   - URL: https://www.runatlantis.io/
   - 面向 Terraform 的 GitOps
   - 通过 PR 自动执行 plan/apply
   - 自托管

9. **env0** - Terraform Cloud 替代方案
   - URL: https://www.env0.com/
   - 托管 Terraform 平台
   - 成本追踪
   - 策略执行

10. **Spacelift** - 高级 IaC 平台
    - URL: https://spacelift.io/
    - 支持多种工具（Terraform、Pulumi 等）
    - 高级工作流

## 面向 ML/AI 基础设施的实践项目

### 初级项目

1. **单 GPU 训练服务器**
   - 1 台 EC2 p3.2xlarge 实例
   - 用于数据集的 S3 存储桶
   - 安全组配置
   - 用于访问 S3 的 IAM 角色

2. **多环境配置**
   - 开发、预发布、生产环境
   - 使用工作区或目录
   - 为不同环境选择实例类型

3. **自动扩缩容的推理集群**
   - 自动扩缩容组
   - 负载均衡器
   - CloudWatch 告警

### 中级项目

4. **完整的 ML 训练平台**
   - 带 GPU 节点的 EKS 集群
   - 使用 S3 存储数据和模型
   - 使用 ECR 存储 Docker 镜像
   - 包含公有及私有子网的 VPC
   - 使用 Prometheus/Grafana 监控

5. **多云部署**
   - 在 AWS 和 GCP 上部署相同 ML 工作负载
   - 使用 Terraform 或 Pulumi
   - 与云平台无关的模块设计

6. **GitOps 工作流**
   - 用于 Terraform 的 GitHub Actions
   - 在 PR 时自动执行 plan
   - 合并时自动执行 apply
   - tfsec 安全扫描
   - Infracost 集成

### 高级项目

7. **企业级 ML 平台**
   - AWS 多账户配置
   - 中心辐射式网络设计
   - 集中式日志与监控
   - 成本分配标签
   - 合规策略（OPA）

8. **Kubernetes 原生 ML 基础设施**
   - 使用 Kubeflow 的 EKS
   - GPU 节点池
   - 自动扩缩容
   - 服务网格（Istio）
   - 使用 ArgoCD 实现 GitOps
