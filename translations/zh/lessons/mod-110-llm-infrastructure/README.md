# 模块 10：LLM 基础设施

## 模块概览

欢迎来到 AI 基础设施工程师课程的最后一个模块！本模块涵盖大语言模型（Large Language Model，LLM）基础设施——现代 AI 系统中发展最迅速、最关键的领域之一。随着组织越来越多地采用 LLM 来构建聊天机器人、代码生成、文档分析及众多其他应用，部署、扩展和优化 LLM 基础设施的能力已经成为 AI 基础设施工程师的必备技能。

LLM 基础设施面临不同于传统机器学习基础设施的独特挑战：

- **庞大的模型规模**：模型参数从 70 亿到 700 亿以上，需要专门的硬件和服务策略。
- **高计算需求**：GPU 集群、显存优化与高效资源分配。
- **复杂部署模式**：推理服务、微调流水线、RAG 系统与多模型平台。
- **成本考虑**：在性能与可能迅速增长的基础设施成本之间取得平衡。
- **快速创新**：新的优化技术、量化方法与推理服务框架不断出现。

本模块将为你提供构建生产级 LLM 基础设施所需的知识和动手技能，从使用 vLLM 部署第一个模型，到设计具备 RAG 能力的完整多模型平台。

## 为什么 LLM 基础设施重要

LLM 应用的爆发创造了前所未有的工程人才需求，需要工程师能够：

1. **高效部署 LLM**：以优化的延迟与吞吐量提供大规模模型服务。
2. **构建 RAG 系统**：为特定领域应用实现检索增强生成。
3. **优化成本**：通过量化、批处理及资源管理降低基础设施开支。
4. **确保可靠性**：构建具有适当监控与故障转移能力的高可用 LLM 服务。
5. **支持微调**：构建利用组织数据定制模型的基础设施。
6. **设计平台**：构建支持多种模型及使用场景的完整 LLM 平台架构。

企业正在向 LLM 基础设施投入数十亿美元，熟练工程师具有薪酬溢价。理解 LLM 基础设施能够帮助你参与当今技术行业中具有吸引力的项目。

- 开发：具有 16GB 以上内存的 CPU 环境（用于较小模型与原型开发）。
- GPU 练习：可访问云 GPU 实例（T4、A10G 或 A100）。

  - GCP：配置 T4 GPU 的 n1-standard-4。
  - Lambda Labs、RunPod 或类似 GPU 云提供商。
- 存储：50GB 以上，用于下载模型与数据集。

**注意**：大多数练习可以使用适量 GPU 资源完成。我们重点关注能够在消费级 GPU 上运行的 70 亿参数模型，并提供具有成本效益的云端选择。
